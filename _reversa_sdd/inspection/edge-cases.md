# Inspeção de frentes (inspection) — Casos Extremos

🟢 **CONFIRMADO** — comportamentos lidos em `caffmob_draw/inspection/` em 2026-10-10 (sem execução no Blender). Descrevem o que o código **faz**, não o que deveria fazer.

| ID | Cenário | Comportamento observado no código | Fonte | Confiança |
|---|---|---|---|---|
| EC-01 | Folha convertida de correr (`btm_aggregate.motion = 'SLIDE'`) ativa e selecionada | `AggregateLeafFront` é `DRAWER`, então o gizmo mostra a seta; `_arrow_get`/`_arrow_set` chamam `front.travel()`, que não existe nem na subclasse nem na base `Front` → `AttributeError` a cada leitura do gizmo. O clique, "Abrir tudo" e a interferência não usam `travel` e funcionam | `gizmo.py:_arrow_get/_arrow_set`; `adapters/aggregate_leaf.py`; `fronts.py:Front` | 🟢 (código) / 🟢 **Decisão do titular (2026-10-10, questions.md#pergunta-61):** implementar `travel()` em `AggregateLeafFront` com o curso de correr da folha (`aggregates/leaf.py`) e um `travel()` na base `Front` devolvendo 0, com a seta oculta quando 0 (contrato uniforme entre adaptadores). Pendência de implementação: DT-01 |
| EC-02 | Folha convertida de giro com `max_angle` > 90 (ex. 110°) | Clique e `OPEN_90` usam `open_value(90)` → 90°, nunca o máximo; o dial passa por `snap_angle`/`clamp_angle` com teto fixo de 90 → não passa de 90°. Pendência de implementação: DT-02 |
| EC-03 | Esc ou botão direito no meio de uma animação | `_finish` grava o **alvo** (`commit(target)`): a porta termina aberta (ou fechada) instantaneamente; não volta ao valor anterior | `ops_inspect.py:_finish` | 🟢 |

| EC-06 | Objeto de módulo compartilhado entre duas cenas, uma com `save_fronts_open = True` e outra sem | A cena com a opção é pulada, mas a outra fecha a mesma frente (mesma `key`) — o objeto compartilhado é salvo fechado | `save_guard.py:close_for_save/_saves_open` | 🟢 / 🟢 **Decisão do titular (2026-10-10, questions.md#pergunta-63):** aceito o comportamento atual para cenas compartilhadas (o objeto é salvo fechado, o lado seguro) |

Pendência de implementação: DT-03 |

Em ambos os casos a frente não entra em `checked_fronts`; com só esses casos o painel diz "Nenhuma frente verificada" | `interference.py:check_fronts/_world_corners`; `adapters/room_doors.py:can_sweep` | 🟢 |
