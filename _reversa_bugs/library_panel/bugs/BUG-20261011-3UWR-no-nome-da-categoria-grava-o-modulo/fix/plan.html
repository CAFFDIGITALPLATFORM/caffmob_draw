Causa raiz

  • BUG-20261011-3UWR · confirmed: validate_name só recusava / e \; o módulo salvo vai para a pasta saneada por file_stem, diferente da pasta da categoria.

          Correção direta: validate_name recusa o que file_stem troca (nome ≠ file_stem(nome)); save guarda categories.json.bak quando a última leitura achou o arquivo inválido e avisa; _count devolve 0 com aviso para não numérico; null vale como ausente.
